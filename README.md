# Pokemon Clustering Analysis

This project explores unsupervised machine learning techniques applied to the Pokémon dataset.

## Techniques Used
- K-Means Clustering
- DBSCAN
- Data preprocessing
- Feature scaling
- Cluster evaluation metrics
- Data visualization

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Objective
Analyze patterns and hidden structures within Pokémon attributes through clustering techniques.
